Introduction

lp is a PyQt5 desktop music player that also supports podcasts and internet radio. It is designed as a teaching example for a Python II course — the codebase is intentionally flat (all source in src/, no subpackages) and favors explicit wiring over abstraction layers.

This guide is written for a software development instructor or experienced developer who needs to quickly understand where things are and how they connect. It follows the principles from UC Berkeley's guide on writing good documentation: lead with purpose, use visuals to explain structure, provide concrete "how-to" paths, and keep reference material scannable.

Audience: You already know Python and Qt basics. This doc focuses on this codebase's specific patterns, not general Qt tutorials.

Quick Start

# Activate venv and run
source venv/bin/activate
python src/app.py

# Build a standalone binary
pip install -r requirements.txt
pyinstaller lp.spec

CI builds are triggered by pushing a v* tag. Builds run on Linux (ubuntu-22.04), macOS, and Windows using Python 3.12.

Adding a New Widget to the Main Layout

  1. Create the widget class in a new src/your_widget.py
  2. Import and instantiate it in App.__init__ (around line 158)
  3. Add it to the splitter: self.splitter.addWidget(self.your_widget) (around line 214)
  4. Set stretch factor and collapsible: self.splitter.setStretchFactor(N, weight)
  5. Add a toggle button if needed (follow the pattern at lines 309-327)
  6. Add QSS styling in theme.py — add a new your_widget_qss(t, fs) function
  7. Call your QSS function from App.apply_theme()

Panel Toggle System

Each panel's visibility is managed through a consistent pattern:

  1. Toggle button in the toolbar (e.g., toggle_tracklist_btn)
  2. Toggle method that calls _toggle_panel(widget, show) — see app.py:939-957
  3. Space redistribution: when hiding a panel, its space goes to the Player; when showing, space is taken from the Player. This prevents jarring layout jumps.
Important: _toggle_panel() manipulates splitter sizes directly, not just visibility. If you just call widget.setVisible(False), the panel collapses but leaves dead space. Always use _toggle_panel() or follow its pattern.

Focus and Selection Highlighting

The folder view and tracklist use focus-aware styling: the selection highlight color changes depending on which pane has keyboard focus. This is implemented by:

  1. QApplication.focusChanged signal → App._on_focus_changed
  2. Which calls _apply_pane_styles() — regenerates QSS with focused=True/False
  3. The QSS functions folder_view_qss() and album_view_qss() accept a focused parameter

See theme.py:317-379 for the focused/unfocused QSS differences.

Display Modes

Normal Mode

The default three-panel splitter layout. All panels are resizable by dragging splitter handles. Panel visibility is toggled with toolbar buttons or keyboard shortcuts (4/5).

Max Mode (Fullscreen)

Activated by Shift+M or clicking album art. Implemented in:

  • enter_maxplayer() — app.py:1123: saves state, hides splitter/toolbar, builds fullscreen widget
  • exit_maxplayer() — app.py:1350: destroys max widget, restores saved state
  • _style_max_mode() — app.py:1223: applies theme with larger font sizes

Accent Color Pipeline

graph TD ART["Album art loaded"] EXTRACT["PaletteExtractThread
color_extract.py"] PALETTE["Color palette (5 colors)"] READABLE["most_readable()
WCAG contrast check"] ACCENT["accent_color"] CONTRAST["ensure_contrast()

When "Accent Match" is enabled (Theme menu), the accent color automatically adapts to each album's cover art. The pipeline:

  1. Album art loaded → _update_accent_for_album()
  2. Background thread extracts palette from cover image
  3. most_readable() picks the color with best contrast against both light and dark backgrounds
  4. ensure_contrast() adjusts if the chosen color fails WCAG 3:1 against the current theme background
  5. Per-album accent choices are saved in _album_accents dict and persisted to QSettings

How to Change Theme Colors

  1. Edit the LIGHT or DARK dict in theme.py:6-32
  2. If adding a new token, use it in the relevant QSS function(s)
  3. The QSS functions are called from App.apply_theme() — see app.py:379-402
  4. Font is resolved at startup (resolve_font()) and stored as theme.FONT

Adding a New Mode

To add a fourth mode (e.g., "audiobook"):

  1. Create the left panel widget — follow radio_view.py as a template. Emit a signal when the user selects something.
  2. Create a data class — mimic Album/Track interface: needs tracklist, path, art, title, artist. Each item needs title, length, path, length_to_string().
  3. Register in App.__init__:
    • Create the widget and add to splitter (hidden by default)
    • Connect its selection signal
    • Add a mode toggle button
  4. Add to _set_mode(): handle showing/hiding the new panel
  5. Add to _apply_controls_for_mode(): configure player buttons for the new mode
  6. Add QSS function in theme.py and call from apply_theme()
  7. Add save/restore in closeEvent() and _restore_state()

File-by-File Reference

Core

app.py — Main Window Orchestrator

Classes: _HoverRevealBar, ToolBar, App

Sections (marked with # ── Section ── comments):

  • Theme & Styling — apply_theme(), toggle_theme(), accent color management
  • Session Persistence — _restore_state(), closeEvent()
  • Keyboard Shortcuts & Input — _setup_shortcuts(), eventFilter(), keyPressEvent()
  • Panel Visibility & Layout — toggle methods, _toggle_panel()
  • Lyrics & Track Change Handling — _on_track_changed(), lyrics fetch/display
  • Max Mode — enter_maxplayer(), exit_maxplayer()
  • Mode Switching — _set_mode(), control mode adaptation
  • Podcast Mode — episode download, feed loading, podcast playback
  • Radio Mode — station streaming, metadata display, art picker

player.py — Playback Engine + UI

Key class: Player(QWidget)

Owns the just_playback.Playback instance and a 20ms QTimer for progress updates. Emits track_changed, track_finished, and art_clicked signals.

Important: just_playback requires play() before pause()/seek() will work.

album_view.py — Tracklist Panel

Classes: AlbumLoadThread, WrapIndentDelegate, AlbumView

Uses VimListWidget for the track list. Loading runs in a QThread. In podcast mode, the click handler is disconnected and replaced by App.

folder_view.py — Library Browser

Key class: FolderView(QWidget)

Uses QFileSystemModel filtered to directories. Double-click on a folder with music files loads it into AlbumView. Context menu opens the folder in the system file manager.

Data

track.py — Track Data Class

Plain data class. All string fields are str()-converted in __init__ to avoid mutagen lazy-evaluation objects persisting beyond the file handle.

album.py — Folder Parser

Scans a directory for .mp3/.flac/.m4a files, extracts metadata with mutagen, falls back to filename parsing. Filters out full-disc rips (single huge file).

podcast_feed.py — RSS Parser + Data Classes

PodcastFeed mimics Album, PodcastEpisode mimics Track — so the Player widget can handle them identically. Includes download threads with progress reporting.

radio_station.py — Station Data Class

Minimal Track-compatible data class: just name and stream_url.

Playback

radio_player.py — Radio Streaming

Factory function _make_radio_player() returns either _QtRadioPlayer (QMediaPlayer) or _SubprocessRadioPlayer (ffplay/mpv subprocess for frozen Linux builds). Also contains StationArtDialog for searching station logos via DuckDuckGo Images.

media_keys.py — Cross-Platform Media Keys

Two layers: (1) Qt event filter for focused-window keys, (2) native global hooks (MPRIS2/D-Bus on Linux, NSEvent on macOS, low-level keyboard hook on Windows).

UI Components

theme.py — Theme Definitions + QSS

Two theme dicts (LIGHT/DARK) plus QSS generator functions. Font is resolved at startup. Accent presets are also defined here.

vim_views.py — Vim Navigation

VimTreeView and VimListWidget with j/k/h/l/Enter navigation. Uses ShortcutOverride to let non-vim keys pass through to QShortcut handlers. SearchBar is a QLineEdit that returns focus on Escape/Enter.

progress_bar.py — Clickable Progress Bar

Click-to-seek and drag-to-scrub. Emits seek_requested during drag (pauses playback) and start_playback on release (resumes).

marquee_label.py — Scrolling Text

Winamp-style horizontal text scroller for long track titles. Auto-detects overflow and starts scrolling with a configurable pause at the start.

lyrics_widget.py — Lyrics Display

Renders plain text, synced LRC lyrics (with highlight + auto-scroll), or podcast descriptions with clickable timestamps. Click on a synced line seeks to that position.

Network

lyrics_fetcher.py — LRCLIB API

Three-stage search: exact match, cleaned album name, then search fallback. Caches results in album/lyrics/ directory.

artwork_finder.py — iTunes Artwork Search

Dialog that searches iTunes for album art, shows thumbnails, and downloads high-res cover.jpg to the album folder.

color_extract.py — Palette Extraction

Downsamples album art to 60x60, bins pixels by HSV, scores by area coverage and visual prominence. most_readable() picks best WCAG contrast ratio.
